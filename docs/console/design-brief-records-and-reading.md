## A. The idea, and the rules that run through it

**The idea, in seven sentences.**

1. The cluster answers four questions: **what must we hold, and do we** (the checklist); **what did jason find in this file, and where does it doubt itself** (the intake review); **what do these documents say about this question, in their own words** (the careful reading); **what does this member's request owe, and by when** (the records request).
2. Every reading jason makes of a file is **evidence beside the file**. The original is never changed, split, or cleaned in place. A tier is a count of readers, never a percentage. A hit is evidence, not a pin.
3. A person pins, confirms, answers, or says none exists, in their own name, behind a `Confirm` that shows a dry run first. Empty is not "none exists"; "not applicable" and "does not exist" are different answers a person gave.
4. The screen orders a person's time: the worst-read file first, the quick likely readings apart from the guarded ones, the biggest unknowns first.
5. A quotation leaves jason as stored words with its verdict, or a named person gives it as written, on the record.
6. A records request runs on the statute's clocks: recited whole, then jason's computed date labeled as computed, then the person's act.
7. Each is a run in Work; the run embeds reads and links writes, and a child run never completes its parent's gate.

**The rules** (each is in a spec; a screen that breaks one is wrong):

- **Directors and officers have the same access to information.** There is no director-only or counts-only view. The server decides what a level opens (P0 to P3); the page renders it. Every screen here is board only; the owner view reads none of it except the request form and the record kinds.
- **A confidential file is held back unless asked.** It is counted, never listed, outside the private view (bank statements, owner histories, executive sessions, the member list, ballots, counsel's letters); inside it, each opening is one logged view. Its name, page images, crops, text layer, and titles do not load. A slot shows "a confidential file (kind: legal)" and "opens in the private view". The restricted 5200 records are listed by kind only.
- **OCR text can be wrong, so it is shown as the file's words.** The crop of the page sits beside every reading; the readers are labeled (text rules, page crop, working copy); the OCR's own reading is "as read", first. Accepting records a person's transcription and leaves the stored text unchanged; the card says so. A change to a number or an operative word is never in a bulk and opens its crop first.
- **A reading is evidence until a person confirms it.** A pick is "you picked X for Y; jason read it as Z (likely or suggested, by which readers); what it found; what you confirm". A wrong-slot pick is shown, never silently accepted, and nothing moves until a preview is confirmed. A model's answer below its floor is a question, never a filing. A miss stays a miss: "no kind", "no book", "not in any document jason found".
- **jason files nothing to Drive without a plan a person approves.** A pick records which file is meant and moves, copies, renames, and shares nothing; a bound folder is a candidate source, never a pin; a sync rule is proposed as text and applied by a person; copying a handed-over box into the library is `jason ingest --apply` today (terminal) and a proposed one-person plan (`local.ingest.apply`) later. A new version of a recited document is reported and applied by no control.
- **A records request has statutory clocks.** Recite CIV 5210(b) verbatim from `data/authorities` (the 10 business days, the 30 calendar days), then label jason's reading. A computed date says "jason's computed date, for a person to check" (business days are Monday to Friday, no holidays; the fiscal year is read as the calendar year). It never reads "satisfied" without the production date a person recorded. **The membership-list clock stays with counsel:** show 5210(b)(6) and the CORP 8330 timeframes it points to side by side, label jason's five-business-day count as a computed date, and never call it the deadline.
- **The copy cost and the redaction cap are the statute's words.** CIV 5205(f) (agree to the costs before copying and sending) and 5205(g) (the hourly rate and the total cap for redacting an enhanced association record) are recited, never paraphrased. An estimate above the cap shows the statute's sentence and asks the manager for a reason; the page never lowers a number or decides a fee. Amounts are integer cents.
- **Recite the rule; label the reading.** Quote, then cite; the version in force on the relevant day, with the caveat that jason's text is not an official restatement. A found quotation says the words are stored, not that the answer reads them rightly. The words "verified", "approved", "accepted" alone, "complete", "relevance", and any percentage appear on no control.
- **Every state is a word and a glyph, never colour alone.** A page cell carries its number and its word; a tier, a move, a verdict, and a slot's state each carry theirs.
- **Names in a URL are never allowed.** A route carries a slot key (URL-encoded), a draft id, a file id (`sha-…`), a page number, or a run id (opaque: `run-` and ten hex); never a file name, a Drive id, a unit, or search words (searches and name filters are POSTs).

### C2. A document's intake review (no loader, no view)

### C3. The careful reading of one document (no loader, no view)
